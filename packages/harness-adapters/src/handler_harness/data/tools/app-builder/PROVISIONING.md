# Apps tool — provisioning

Nothing to provision: the tool brings the skill, and needs no account nor connection (it is given
by its name). Bun comes with its image.

1. An agent on the app's folder that uses it, with only these sites on its network (the tool adds
   `registry.npmjs.org`, for the UI's build and the backend's type check).
2. When the agent is done: Apps → Add (the folder) → Deploy. Only you deploy.
