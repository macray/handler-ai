# handler inbox

Show what Handler told you, newest first: your apps' notifications, your agents' results (run by
an automation or by one of your apps), the runs and plans that failed, and the hosts the network
filter blocked while you were away. The same as the web UI's Inbox. `OPENS` is the app a message
opens: `handler app open NAME`. Below the list, the messages with hosts not answered yet: allow
them or keep them blocked in the web UI's Inbox.

## When to use it

- To read what an automation's agent found.
- To see why an automation's run or a plan failed.
- To see which hosts the network filter blocked while you were away.
- To catch up on an app's notifications, and the results of the agents it ran for you.

## Usage

```
handler inbox
```
