# handler inbox

Show what Handler told you, newest first: your apps' notifications, your agents' results (run by
an automation or by one of your apps) and the runs that failed. The same as the web UI's Inbox.
`OPENS` is the app a message opens: `handler app open NAME`.

## When to use it

- To read what an automation's agent found.
- To see why an automation's run failed.
- To catch up on an app's notifications, and the results of the agents it ran for you.

## Usage

```
handler inbox
```
