# handler inbox

Show what Handler told you, newest first: your apps' notifications, your automations' results and
failures. The same as the web UI's Inbox.

## When to use it

- To read what an automation's agent found.
- To see why an automation's run failed.
- To catch up on an app's notifications.

## Usage

```
handler inbox
```
